## 2024-07-03 - Intl Formatter Caching Optimization
**Learning:** Instantiating `Intl.NumberFormat` and `Intl.DateTimeFormat` dynamically within React component render paths or helper functions re-creates the formatter on every execution. In this project, these were widely spread across 15+ screen components, potentially blocking the JS thread on frequent updates.
**Action:** Extract all commonly used specialized formatting configurations (e.g. `currency: 'USD'`, `notation: 'compact'`, `minimumFractionDigits: 2`) into a shared utility file (`src/utils/formatters.ts`) as exported, cached, pre-bound `.format` methods to eliminate re-instantiation overhead. Added comments explaining the optimization pattern. Always double check automatic refactoring for self-referencing functions and lingering ad-hoc `.js` script files.
