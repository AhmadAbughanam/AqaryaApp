## 2024-05-18 - Caching Intl Formatters
**Learning:** Found multiple usages of `new Intl.NumberFormat()` and `new Intl.DateTimeFormat()` inside component render loops across 18+ different files. React Native components re-rendering frequently makes inline instantiation of `Intl` objects a performance bottleneck. Centralizing and caching these formatters is a highly effective, safe micro-optimization that has significant cumulative impact on render speeds.
**Action:** Always extract and export cached instances of `Intl` formatters (e.g., currency, numbers, exact decimals, dates) into a utility file (`src/utils/formatters.ts`) and use these exported instances throughout the codebase instead of creating new instances inline. Added comment explaining caching intention for future developers.
