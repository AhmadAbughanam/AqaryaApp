## 2024-05-18 - Cached Intl Formatters for Mobile Performance
**Learning:** Instantiating `Intl.NumberFormat` inside React render functions causes significant performance bottlenecks, particularly in lists or complex UI where re-renders occur frequently. `Intl` objects take CPU cycles to parse formatting options and locales. While `React.memo` or `useMemo` can help limit rendering overhead, extracting and caching `Intl` formatters globally using their bound `.format` accessor property is far more effective. Also, special cases exist (like `compact` notation) which must be individually captured in custom exported functions instead of being blindly overwritten.
**Action:** Always scan for inline `new Intl.NumberFormat` or `new Intl.DateTimeFormat` within render functions and hoist them out to a cached `utils/formatters.ts` file. Ensure to verify specific formatting parameters used locally to define the accurate cached options. When substituting globally, export the bound `Intl.NumberFormat(...).format` directly rather than building a wrapper.
