## 2024-07-05 - Intl.NumberFormat Instantiation Bottleneck in React Renders
**Learning:** Instantiating `Intl.NumberFormat` or `Intl.DateTimeFormat` inline within React functional components causes significant performance bottlenecks because these constructors are incredibly slow (~1193ms vs ~11ms for 10k ops in benchmark). This causes unnecessary UI thread lag, particularly when rendering lists of properties or financial dashboards.
**Action:** Always cache and reuse `Intl` formatters globally (e.g., in `src/utils/formatters.ts` by exporting the bound `.format` method) rather than passing configurations inline in components. During automated refactoring of such formatters, always ensure the local wrapper is stripped entirely to prevent infinite recursion (`const formatNumber = (v) => formatNumber(v)`).
