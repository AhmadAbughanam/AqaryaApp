# Competition Demo Checklist

## Before The Demo

- Apply migrations and seed the database.
- Start the backend.
- Start Metro.
- Install/open the app on the emulator or device.
- Confirm seeded credentials work:
  - `citizen / 123456`
  - `admin / 123456`
- Confirm the API URL is reachable from the demo device.
- Prepare screenshots or a short backup video.

## Core Story

Keep the story focused:

1. Citizen trust problem.
2. SANAD-style identity and DLS-style verification.
3. Verified property listing for citizens.
4. Citizen sale listing enters review.
5. Admin review and auditability.
6. Notifications and analytics close the service loop.

## Avoid

- Leading with investment.
- Calling the app only a real-estate marketplace.
- Claiming live SANAD or DLS integration unless it is officially connected.
- Showing too many admin modules in the first two minutes.
